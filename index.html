Half-QWERTY Typing Class

Welcome to the Half-QWERTY one-handed typing page. This site presents the AutoHotkey script from the halfqwerty-master folder and explains how to use it as a typing tool.

Tip: To try this on Windows, download halfkeyboard.ahk and run it with AutoHotkey installed.

What this does

The script remaps the right-hand side of your keyboard to a one-handed "half QWERTY" layout using the Space key as a modifier. It is useful for one-handed typing practice and keyboard accessibility.

How to use it

  1. Install AutoHotkey from autohotkey.com.
  2. Download halfkeyboard.ahk.
  3. Run the script by double-clicking it.
  4. Hold Space and press a right-side letter to type the mirrored character.
